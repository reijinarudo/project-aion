# keys/

Everything in this folder except this README is gitignored.

- `openai.key` (optional): a text file holding only your OpenAI API key. Used when OPENAI_API_KEY is not set in the environment or in .env.
- `google_credentials.json` (optional): OAuth client file for Google Calendar. See docs/integrations.md.
- `google_token.json`: created on the first calendar run after you approve access in the browser. Delete it to sign in again.
